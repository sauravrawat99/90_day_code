📘 2️⃣ Aaj ke DSA SORTING NOTES (EXAM + INTERVIEW)
🔹 1. Bubble Sort

Idea: Bade element ko bubble ki tarah end me bhejna

for i = 0 → n-1
 for j = 0 → n-i-1
  if arr[j] > arr[j+1]
    swap


⏱ Time: O(n²)

🧠 Easy, but slow

👍 Small input ke liye

🔹 2. Selection Sort

Idea: Har round me smallest element uthao aur sahi jagah rakho

for i = 0 → n-1
 min = i
 for j = i+1 → n
  if arr[j] < arr[min]
    min = j
 swap


⏱ Time: O(n²)

🔄 Swaps kam

❌ Not stable

🔹 3. Insertion Sort

Idea: Cards jaisa sort (left part sorted)

for i = 1 → n-1
 key = arr[i]
 j = i-1
 while j>=0 && arr[j] > key
  arr[j+1] = arr[j]
 arr[j+1] = key


⏱ Best: O(n)

⏱ Worst: O(n²)

👍 Nearly sorted array ke liye best

🔹 4. Counting Sort (Special)

Idea: Count frequency (NO comparison)

⏱ Time: O(n + k)

❌ Negative numbers ❌

👍 Small range numbers

📊 Quick Comparison Table
Sort	Time	Stable	Use Case
Bubble	n²	✅	Learning
Selection	n²	❌	Swaps kam
Insertion	n²	✅	Nearly sorted
Counting	n+k	✅	Small range
🧠 Interview One-Liners

Spiral Matrix → boundary shrink logic

Insertion Sort → best for nearly sorted array

Selection Sort → minimum swaps

Bubble Sort → slow but simple

Diagonal Matrix – Short Notes
✅ What is a Diagonal Matrix?

A diagonal matrix ek square matrix hoti hai jisme
👉 sirf diagonal elements non-zero hote hain
👉 baaki sab elements 0 hote hain.

📌 Example:
[ 5  0  0 ]
[ 0  3  0 ]
[ 0  0  8 ]

🔹 Types of Diagonals
1️⃣ Primary Diagonal

Left-top → Right-bottom

Condition: i == j

matrix[i][i]

2️⃣ Secondary Diagonal

Right-top → Left-bottom

Condition: i + j == n - 1

matrix[i][n - 1 - i]

🔹 Diagonal Sum
✅ Primary Diagonal Sum
sum += matrix[i][i];

✅ Secondary Diagonal Sum
sum += matrix[i][n - 1 - i];

🔹 Both Diagonal Sum (Center repeat avoid)
if (n % 2 !== 0) {
  sum -= matrix[mid][mid];
}

🔹 Check Diagonal Matrix
function isDiagonal(matrix) {
  for (let i = 0; i < matrix.length; i++) {
    for (let j = 0; j < matrix.length; j++) {
      if (i !== j && matrix[i][j] !== 0) {
        return false;
      }
    }
  }
  return true;
}

🔹 Important Conditions (Yaad rakhna 🔥)

✔ Must be square matrix

✔ Only diagonal elements ≠ 0

✔ i ≠ j → value must be 0

🔹 Time & Space Complexity

Time: O(n²)

Space: O(1)

🔹 Interview One-Line Answers

Diagonal element: i == j

Secondary diagonal: i + j == n - 1

Center element: n / 2

Matrix must be: square

🔹 Very Short Summary (Exam)

Diagonal matrix is a square matrix where all non-diagonal elements are zero.
